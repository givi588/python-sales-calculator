# Python Sales Calculator

A beginner-friendly Python application that calculates product revenue and generates a simple sales report.

## Features

- Calculates revenue for multiple products
- Uses lists and dictionaries to organize product data
- Uses functions to calculate totals
- Generates a sales summary
- Evaluates whether a sales target has been achieved

## Technologies

- Python 3
- No external libraries required

## Example Output

```text
=== SALES REPORT ===
Keyboard - 400 GEL
Mouse - 140 GEL
Monitor - 600 GEL
Headphones - 360 GEL
--------------------
Grand Total: 1500 GEL
Sales Target: Achieved
```

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run:

```bash
py main.py
```

On systems where `py` is unavailable, use:

```bash
python main.py
```
